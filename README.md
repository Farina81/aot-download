# Age of Tritium

A real-time strategy game for Windows: capture and hold flags, build a base and extractors, research through three eras, and fight with infantry squads, tanks, mines and helicopters.

## Download

**[AgeOfTritium-win64.zip](https://github.com/Farina81/aot-download/releases/latest/download/AgeOfTritium-win64.zip)** — Windows 10 or 11, 64-bit. About 750 MB to download, 1 GB unpacked.

Unpack it anywhere, open the `AgeOfTritium` folder and run `AgeOfTritium.exe`.

- **Solo vs AI:** free, no account needed.
- **Online:** free, with an account at [ageoftritium.com](https://ageoftritium.com).
